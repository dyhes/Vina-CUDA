# Q4-7M-M2 完成报告 — grid FP16 存储 — 2026-09-11

> 改动已在树上（commit 32e551fe），六档冒烟通过，判定如下。

## 结果

- **性能：零收益**（k2 与 M1 持平，MC 噪声内）——证实 L2 分析：
  12MB grid 常驻 L2，命中时 FP32/FP16 读时间无差异；DRAM 冷 miss
  在 redocking 单遍写读下占比太小
- **显存：136 → 68MB（-50%）**——对 v6-batch（多配体共享 grid）
  与多实例并发有真实价值，保留
- **精度：无法归因**——3ag9 同 seed 双跑差 0.2 kcal，与已知残余
  非确定性（Q4-8 未根除的 m_coords 跨 eval 同步缺失）同量级，
  FP16 截断误差（理论 ~5e-3 kcal）被淹没

## 依赖链发现（优先级修正）

M2 的精度归因 **被 Q4-8 续（确定性根治）阻塞**。Q4 剩余工作顺序
修正为：

```
Q4-8续（确定性根治，1-2 会话）
  → M2 精度归因（同 seed 逐位对比 FP16 截断误差）
  → M4 half2 数学（同前）
  → Q4-9 v6-batch（此时显存 -50% 是前置收益）
```
