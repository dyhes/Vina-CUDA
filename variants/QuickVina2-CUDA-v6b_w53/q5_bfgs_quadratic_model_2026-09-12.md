# BFGS 二次模型假设详解 — 结合 Q5 代码 — 2026-09-12

## 一、二次模型是什么

所有拟牛顿方法（包括 BFGS/RILC）在当前迭代点 xₖ 附近，用一个
二次函数近似目标能量面 E(x)：

```
E(xₖ + Δx) ≈ E(xₖ) + gₖᵀ·Δx + ½·Δxᵀ·Bₖ·Δx
```

其中：
- `gₖ = ∇E(xₖ)` 是当前梯度（代码中的 `change_cl g`）
- `Bₖ` 是 Hessian 近似（RILC 中用单对 s/y 隐式表示）

这个模型的两个用途：
1. **选方向**: `d = -Bₖ⁻¹·gₖ`（代码中 RILC 方向更新）
2. **选步长**: 线搜索沿 d 找使 E 下降的 α（代码中 `stp`）

## 二、模型成立的数学前提

二次模型是泰勒展开截断到二阶。它作为"好的局部近似"需要：

**E(x) 在 xₖ 的邻域内是 C² 连续可微的**（至少 C¹）。

具体来说：
- **C⁰（连续）**: 当 Δx→0 时，E(xₖ+Δx)→E(xₖ)。没有跳变。
- **C¹（可微）**: ∇E 存在且连续。梯度的方向和大小随 x 连续变化。
- **二阶项有意义**: Hessian 反映了真实的曲率信息。

## 三、代码中的每一步如何依赖这个假设

### 3.1 线搜索 Lewis-Overton（`line_search_lewisoverton_update`）

```c
// 每次 trial:
output_type_cl_increment(x, d, *stp, ...);  // x_new = x + stp·d
set_update(x, ...);                         // 构象→原子坐标
*f = m_eval_deriv_update(x, ...);           // E(x_new) + ∇E(x_new)

// Armijo 条件:
if (*f > finit + *stp * dgtest)  →  nu = *stp; brackt = true;
// 曲率条件:
if (g·d < dstest)  →  mu = *stp;
else  →  return count;  // Wolfe 条件满足, 成功
```

**假设**: 当 stp 足够小时，`f(x + stp·d)` 趋近 `f(x) + stp·(g·d)`
— 即 f 沿方向 d 的变化率趋近方向导数 `g·d`。

**FP32 下**: 坐标连续变化 → f 连续变化 → 当 stp 减小时 Armijo
必然满足（因为一阶泰勒项主导）→ LS 收敛。

**FP16 下**: m_coords 以 0.0078Å 步长量化 → 
- 当 `stp·‖d‖ < 0.0078Å` 时, `x_new` 和 `x` 量化到同一个格子
  → `set_update` 写出相同的 m_coords → `f(x_new) = f(x)` 
  → Armijo 变成 `f(x) ≤ f(x) - ε` → **永远不满足**
- 当 `stp·‖d‖` 跨过量化边界时, f 跳变 ±0.002 kcal — 方向随机
→ **LS 无法找到有效步长**

### 3.2 收敛判定（‖g‖ < 1e-5）

```c
if (!(sqrt(scalar_product_update(g, g, n, ...)) >= 1e-5))
    return;  // 收敛, 退出
```

**假设**: ‖g‖ 反映了"离极小值多远"。当 BFGS 收敛到极小值时，
真实梯度 → 0。

**FP32 下**: 梯度计算的数值噪声 ~1e-7（机器精度量级），
‖g‖ 可以降到 1e-5 以下 → 正常触发。

**FP16 下**: m_coords 的量化噪声 0.0039Å（半步）通过插值链传播
到梯度：δg ≈ Hessian × δx ≈ 1-10 × 0.0039 ≈ 0.004-0.04
→ ‖g‖_noise ≈ 0.1（55 维平方和开根号）
→ 即使真实梯度为零，计算出的 ‖g‖ ≈ 0.1
→ **永远 > 1e-5 → 收敛门永不触发**

### 3.3 RILC 方向更新

```c
lm_s[i] = stp × d[i];         // 步长向量
lm_y[i] = g_new[i] - g_old[i]; // 梯度变化
ys = lm_y · lm_s;              // 曲率信息
yy = lm_y · lm_y;
...
d[i] += (α - β) × lm_s[i];    // 方向校正
```

**假设**: `s = stp·d` 和 `y = g_new - g_old` 携带了能量面的真实
曲率信息。这要求 y 是真实梯度变化，而不是量化噪声。

**FP16 下**: y 的噪声来自 m_coords 量化 → y/signal 比在接近极小值
时急剧恶化 → RILC 的方向校正变成噪声注入 → 方向失效。

### 3.4 A2 早期终止门

```c
if (k >= 4) {
    rel_imp = |fxp - fx| / max(|fxp|, 1);
    if (rel_imp < 1e-2) { small_imp_count++; if ≥2: return; }
}
```

**这个门在 FP16 下会正常触发** — 因为它检测的是"改进很小"，
FP16 量化恰好使改进变小。但它触发的时机和效果与 FP32 不同：
FP32 中它检测的是"接近极小值"，FP16 中它检测的是"量化噪声
掩盖了改进"——表面行为相似，但含义不同。

## 四、用一个物理类比总结

```
FP32: 你站在一个光滑的山坡上，用手感（梯度）判断坡度和方向，
      沿着下坡方向迈步。每一步都能感受到地面的连续变化。
      → 你能走到谷底。

FP16: 你站在一个用 1cm 网格铺的**台阶地面上**。你的脚（坐标）
      只能落在网格交点上。你伸手感受坡度（梯度），但手臂的
      精度也是 1cm — 你感受到的"坡度"在台阶边缘会跳变。
      → 你迈出一小步，发现高度没变（同一格）→ 认为到了平地。
      → 你迈出一大步，跨过台阶边缘 → 高度跳变 1cm → 无法判断
        是真的下坡还是台阶跳变。
      → 你永远无法确认自己是否在谷底（因为精度不够分辨）。
```

BFGS 的所有组件（方向、步长、收敛判定、曲率估计）都建立在
"能量面是光滑的"这个假设上。**坐标 FP16 量化破坏的不是某个
组件，而是这个基础假设本身** — 这就是为什么逐个修补组件
（放松门限、加碰撞保护、调步长）都无法恢复性能。

## 六、如果一定要用 FP16 状态

唯一理论上可行的方式 = **带误差补偿的低精度计算**
（类似 Ozaki 方案 2508.00441 或 GMRES-IR 2109.01232 的思路）：

1. FP16 存储 + FP32 影子副本 + 差值校正
   → 但需要双倍存储(违背 FP16 容量初衷)
2. 随机舍入(stochastic rounding)使量化误差统计 unbiased
   → 不改变单次不连续性, 但多次迭代后统计收敛 — 研究级
3. 混合精度迭代: 每 N 步做一次 FP32 精确重置
   → 类似迭代精化, 但 N 的选择是新的超参数

以上全部超出"配置调整"范畴，属于**新的算法研究**，
需要 design-first 立项和独立的文献调研。
