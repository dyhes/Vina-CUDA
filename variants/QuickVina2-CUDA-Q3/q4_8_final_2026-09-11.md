# Q4-8 确定性根治：阶段总结与最终状态 — 2026-09-11

## 调查方法与证据链

1. **racecheck**（compute-sanitizer）：72 个 race 报告
   - 49 个：mutate_conf.cuh:306 区域（mutate 分支 divergent 写，判定为
     benign 同值多写）
   - 散布：local_to_lab/g_evaluate 等（同步缺失点）
2. **着色修复**：pairs 累加按边着色分相同步 → 消除 pairs 阶段竞态
3. **skip_row RMW**：多线程同 word 位操作 → atomicAnd/Or
4. **RESCHK 校验和**：同 seed 双跑 raw results 缓冲 → **校验和不同**，
   证实 kernel 输出跨 run 非确定
5. **BESTOUT/LS-trace/mutate-trace**（block0）：**逐位相同** → 非确定
   发生在**其他 block**，机制 = LSB 差 → LS 阈值判定翻转 → 轨迹分叉

## 已落地的修复（保留在树上）

| 修复 | 效果 |
|---|---|
| pairs 累加 edge-coloring + 按色同步 | 消除 minus_forces 累加竞态 |
| skip_row atomicAnd/Or | 消除位图 RMW 竞态 |

## 未根除的残余

同 seed 双跑：block0 输出逐位相同，但**其他 block** 的结果缓冲校验和
不同 → mode2-9 的输出坐标差 ~0.05Å、affinity 差 ~0.1-0.4。来源判定：
**LS 内部某处仍存在值不同的写或读交错**（racecheck 的 benign 判定不可
靠——同值多写它无法区分），需要逐 shared 写审计。

## 收益-成本最终判定

- 性能收益：**零**（修复 = 加同步/原子，略慢）
- 质量收益：**零**（本就在噪声带内）
- 工程收益：确定性后，未来优化的 A/B 验证从“CASF 全量 + 分布比较”
  变为“diff 输出文件”——**每次迭代的验证成本从分钟级降到秒级**
